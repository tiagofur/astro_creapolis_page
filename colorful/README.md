# Creapolis - Versión Moderna ✨

Diseño completamente nuevo, limpio y profesional para Creapolis. Inspirado en sitios modernos como Linear, Stripe y Vercel.

## 🎨 Filosofía de diseño

**Moderno, minimalista y elegante** - Nada de colores chillones ni diseños recargados. Un enfoque profesional y contemporáneo que deja respirar el contenido.

### Características clave:

- **Glassmorphism sutil** - Efectos de vidrio esmerilado para nav y cards
- **Gradientes sofisticados** - De violeta a cyan, suaves y elegantes
- **Tipografía moderna** - Space Grotesk para headlines, Inter para body
- **Micro-interacciones** - Hover effects sutiles pero impactantes
- **Espaciado generoso** - Diseño que respira, sin sentirse abarrotado
- **Bento grid** - Layout moderno tipo "cajas" para servicios

## 🎯 Paleta de colores

```css
Violet:  #8B5CF6  /* Principal - Elegante y moderno */
Cyan:    #06B6D4  /* Complementario - Fresco y tech */
Emerald: #10B981  /* Éxito - Verde natural */
Amber:   #F59E0B  /* Atención - Cálido */
Rose:    #F43F5E  /* Alerta - Vibrante pero controlado */
```

**Neutrales:**
- Background: `#FAFAFA` (Casi blanco, suave)
- Text: `#0F172A` (Gris muy oscuro, alto contraste)
- Secondary text: `#64748B` (Gris medio)

## ✨ Componentes destacados

### Hero Section
- Badge animado con pulse indicator
- Headline grande con gradient text
- CTAs con shadow effects
- Platform badges minimalistas

### Services Bento Grid
- Cards con hover effects sutiles
- Iconos con backgrounds de color
- Tags con colores específicos por servicio
- Bordes que cambian de color al hover

### Projects
- Layout tipo "featured work"
- Mockups simplificados y elegantes
- Grid responsive (2 columnas en desktop)
- Hover effects con shadows de colores

### Legal Pages
- Diseño limpio y escaneabl
- Información agrupada en cards con colores
- Navegación simplificada
- CTA buttons para moverse entre páginas
